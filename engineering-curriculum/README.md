# Personal Software and AI Engineering Curriculum

This is a Python-first learning path inspired by 01-edu. The projects are original adaptations for independent practice. They are separate from the official 01-edu assignments.

## How to work through the projects

1. Start with Phase 01 and work through each phase in order. If a project extends another one, keep a working copy of the earlier project.
2. Continue the **AI Engineering from Scratch** course alongside the phases. Start with its APIs lesson and use the **API Client** project in Phase 07 to practice that lesson.
3. Open each project’s README. Use its example and required test situations to understand what success looks like. Write down your plan and expected test results before you write the implementation.
4. Build the project yourself. Use the tools listed in that project and ask for explanations, hints, or review when needed. Run the tests, verify the setup from a fresh copy, and check off the project when you can explain and demonstrate it on your own.
