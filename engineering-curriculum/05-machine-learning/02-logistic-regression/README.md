## Walk through a real example

1. Make examples in two groups, for instance negative inputs labeled 0 and positive inputs labeled 1. Hold back some examples from both groups.
2. Train on the remaining examples. Predict labels for the held-back examples and calculate accuracy. Compare with a baseline that always picks the most common label.
3. Pass very large raw scores to the loss calculation and check how it handles them.
